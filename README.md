# 📚 Smart Study Planner

## 🧠 Overview

Smart Study Planner is a desktop application designed to help students organize their study time efficiently, manage subjects, and stay consistent with their learning goals.

---

## ✨ Features

* 📌 Add and manage subjects بسهولة
* 🗓️ Create a personalized study schedule
* ⏱️ Track study sessions and progress
* 🔔 Simple and user-friendly interface

---

## 🛠️ Technologies Used

* 💻 C#
* 🪟 Windows Forms

---

### 1. Clone the repository

